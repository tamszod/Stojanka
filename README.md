# Strojanka

A Discord bot that watches stocks and tells each user when a stock has reached a **PEAK** (time to
sell) or a **SUPPORT** level (time to buy). It also tracks your purchases and sales and shows your
profit.

- **Users:** start with [documentation/README.md](documentation/README.md).
- **AI agents working on the code:** start with [agent_documentation/README.md](agent_documentation/README.md).
- **Build:** `build_for_windows.bat` or `./build_for_mac.sh` writes the installer to `dist/`.
